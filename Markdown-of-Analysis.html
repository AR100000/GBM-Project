GBM Analysis

Introduction

This project analyses historical stock price data for UK-listed companies to assess the validity of Geometric Brownian Motion to model the prices. The analysis begins by importing and cleaning the data set and selecting an appropriate historical time period. Daily logarithmic returns are then calculated for each stock, and key statistical parameters are estimated from the resulting data.

The analysis initially focuses on an individual stock, examining its historical price movements, return distribution and volatility statistics. Simulated price paths are subsequently generated and compared with observed prices, with forecast accuracy assessed across different historical estimation windows. Statistical diagnostic tests are also conducted to investigate the distribution of returns, their dependence over time and potential clustering in volatility.

The analysis is then extended across multiple stocks and industries. Simulation performance is compared using percentage errors, root mean squared errors and prediction interval coverage. Statistics per industry are assessed using skewness and excess kurtosis. The results are summarised in tables and graphical comparisons to identify differences between industries and consistent patterns across the entire data set.

Geometric Brownian Motion Equation

\[ S_t = S_0 \exp\left(\left(\mu - \frac{\sigma^2}{2}\right)t + \sigma W_t\right) \]

Estimate Annual Drift and Velocity

\[ \hat{\sigma}=s_r\sqrt{252} \]

where the daily log-return standard deviation is

\[ s_r=\sqrt{\frac{1}{n-1}\sum_{t=1}^{n}(r_t-\bar r)^2} \]

  • \(S_t\) is the stock price at time \(t\).
  • \(r_t\) is the daily log return.
  • \(\bar r=\frac{1}{n}\sum_{t=1}^{n}r_t\) is the mean daily log return.
  • \(n\) is the number of daily log returns.
  • \(252\) is the number of trading days per year.

Annualised Drift

\[ \hat{\mu}=252\bar r+\frac{1}{2}\hat{\sigma}^{\,2} \]

Substituting the volatility estimate gives

\[ \hat{\mu}=252\bar r+\frac{1}{2}(252s_r^2) \]

Equivalently,

\[ \hat{\mu}=252\left(\bar r+\frac{1}{2}s_r^2\right) \]

where \(\hat{\mu}\) is the estimated annualised GBM drift parameter.

The additional term \(\frac12\hat{\sigma}^2\) arises from the GBM model:

It adjusts the annualised mean log return to estimate the drift parameter \(\mu\).

compare_window <- function(prices, window, forecast_days = 21,
                           trading_days = 252) {
  
  # Error Handling
  if (length(prices) < window + forecast_days) {
    return(data.frame(
      Mean_APE = NA_real_,
      Median_APE = NA_real_,
      Mean_Annual_Volatility = NA_real_,
      Forecasts = 0
    ))
  }
  
  errors <- numeric(0)
  volatility_estimates <- numeric(0)
  
  # Rolling forecasts
  starts <- seq(
    from = window + 1,
    to = length(prices) - forecast_days + 1,
    by = forecast_days
  )
  
  for (i in starts) {
    
    estimation_prices <- prices[(i - window):(i - 1)]
    returns <- diff(log(estimation_prices))
    
    sigma_hat <- sd(returns) * sqrt(trading_days)
    mu_hat <- mean(returns) * trading_days +
      0.5 * sigma_hat^2
    
    S0 <- prices[i - 1]
    
    # Expected price after the forecast period
    predicted_price <- S0 * exp(
      mu_hat * forecast_days / trading_days
    )
    
    actual_price <- prices[i + forecast_days - 1]
    
    error <- abs(predicted_price - actual_price) /
      actual_price * 100
    
    errors <- c(errors, error)
    volatility_estimates <- c(volatility_estimates, sigma_hat)
  }
  
  data.frame(
    Mean_APE = mean(errors),
    Median_APE = median(errors),
    Mean_Annual_Volatility = mean(volatility_estimates),
    Forecasts = length(errors)
  )
}

# Compare each estimation window
comparison_list <- lapply(windows, function(w) {
  compare_window(prices, w, forecast_days, trading_days)
})

comparison <- do.call(rbind, comparison_list)

# stock-level gbm statistics

industry_stock_results <- list()

for (industry in names(industry_tickers)) {
  
  tickers <- intersect(
    industry_tickers[[industry]],
    names(data_list)
  )
  
  for (ticker in tickers) {
    
    stock <- data_list[[ticker]]
    
    date_col <- which(tolower(names(stock)) == "date")
    close_col <- which(tolower(names(stock)) == "close")
    
    if (length(date_col) != 1 || length(close_col) != 1) {
      next
    }
    
    dates <- as.Date(stock[[date_col]])
    prices <- suppressWarnings(
      as.numeric(as.character(stock[[close_col]]))
    )
    
    # Use Existing Parameters
    keep <- !is.na(dates) &
      dates >= start_date &
      dates <= end_date &
      is.finite(prices) &
      prices > 0
    
    dates <- dates[keep]
    prices <- prices[keep]
    
    # Sort prices chronologically
    ordering <- order(dates)
    prices <- prices[ordering]
    
    if (length(prices) < 30) {
      next
    }
    
    # Calculate daily log returns
    log_returns <- diff(log(prices))
    log_returns <- log_returns[is.finite(log_returns)]
    
    if (length(log_returns) < 20 ||
        !is.finite(sd(log_returns)) ||
        sd(log_returns) == 0) {
      next
    }
    
    # Estimate GBM parameters using existing trading_days
    sigma_hat <- sd(log_returns) * sqrt(trading_days)
    
    mu_hat <- mean(log_returns) * trading_days +
      0.5 * sigma_hat^2
    
    # Return distribution statistics
    standardised_returns <- (
      log_returns - mean(log_returns)
    ) / sd(log_returns)
    
    industry_stock_results[[length(industry_stock_results) + 1]] <-
      data.frame(
        Industry = industry,
        Ticker = ticker,
        Observations = length(log_returns),
        Mean_Daily_Log_Return = mean(log_returns),
        Annualised_Volatility = sigma_hat,
        Annualised_GBM_Drift = mu_hat,
        Skewness = mean(standardised_returns^3),
        Excess_Kurtosis = mean(standardised_returns^4) - 3
      )
  }
}

diagnostic <- lapply(names(data_list), function(ticker) {

  # Check industry assignment
  if (!ticker %in% assigned_tickers) {
    return(data.frame(
      Ticker = ticker,
      Reason = "Not assigned to an industry"
    ))
  }

  stock <- data_list[[ticker]]

  date_col <- which(tolower(names(stock)) == "date")
  close_col <- which(tolower(names(stock)) == "close")

  if (length(date_col) != 1 || length(close_col) != 1) {
    return(data.frame(
      Ticker = ticker,
      Reason = "Missing or invalid date/close column"
    ))
  }

  dates <- tryCatch(
    as.Date(stock[[date_col]]),
    error = function(e) rep(as.Date(NA), nrow(stock))
  )

  prices <- suppressWarnings(
    as.numeric(as.character(stock[[close_col]]))
  )

  keep <- !is.na(dates) &
    dates >= start_date &
    dates <= end_date &
    is.finite(prices) &
    prices > 0

  dates <- dates[keep]
  prices <- prices[keep]

  prices <- prices[order(dates)]

  if (length(prices) < 30) {
    return(data.frame(
      Ticker = ticker,
      Reason = "Fewer than 30 valid prices"
    ))
  }

  log_returns <- diff(log(prices))
  log_returns <- log_returns[is.finite(log_returns)]

  if (length(log_returns) < 20) {
    return(data.frame(
      Ticker = ticker,
      Reason = "Fewer than 20 valid returns"
    ))
  }

  if (!is.finite(sd(log_returns)) || sd(log_returns) == 0) {
    return(data.frame(
      Ticker = ticker,
      Reason = "Zero or invalid return volatility"
    ))
  }

  data.frame(Ticker = ticker, Reason = "Analysed")
})

#Actual GBM Simulation per Industry

set.seed(123)

n_simulations <- 500
trading_days <- 252

gbm_fit_results <- list()

for (i in seq_len(nrow(industry_stock_results))) {

  ticker <- industry_stock_results$Ticker[i]
  industry <- industry_stock_results$Industry[i]

  stock <- data_list[[ticker]]

  if (is.null(stock)) next

  # Identify required columns
  date_col <- which(tolower(names(stock)) == "date")
  close_col <- which(tolower(names(stock)) == "close")

  if (length(date_col) != 1 || length(close_col) != 1) next

  dates <- as.Date(stock[[date_col]])
  prices <- suppressWarnings(
    as.numeric(as.character(stock[[close_col]]))
  )

  # Apply selected date range and price validity checks
  keep <- !is.na(dates) &
    dates >= start_date &
    dates <= end_date &
    is.finite(prices) &
    prices > 0

  dates <- dates[keep]
  prices <- prices[keep]

  # Sort and remove duplicate dates
  ordering <- order(dates)
  dates <- dates[ordering]
  prices <- prices[ordering]

  unique_dates <- !duplicated(dates)
  dates <- dates[unique_dates]
  prices <- prices[unique_dates]

  if (length(prices) < 30) next

  # Calculate log returns
  log_returns <- diff(log(prices))

  if (length(log_returns) < 20 ||
      !is.finite(sd(log_returns)) ||
      sd(log_returns) == 0) next

  # Estimate annualised GBM parameters
  sigma_hat <- sd(log_returns) * sqrt(trading_days)

  mu_hat <- mean(log_returns) * trading_days +
    0.5 * sigma_hat^2

  # Number of intervals between observed prices
  n_days <- length(prices) - 1

  # Simulate daily log-price increments
  simulated_increments <- matrix(
    rnorm(
      n_days * n_simulations,
      mean = (mu_hat - 0.5 * sigma_hat^2) / trading_days,
      sd = sigma_hat / sqrt(trading_days)
    ),
    nrow = n_days,
    ncol = n_simulations
  )

  # Construct simulated price paths
  simulated_paths <- rbind(
    rep(prices[1], n_simulations),
    prices[1] * exp(
      apply(simulated_increments, 2, cumsum)
    )
  )

  # Pointwise 95% simulation interval and median path
  lower_95 <- apply(
    simulated_paths, 1, quantile, probs = 0.025
  )

  median_path <- apply(
    simulated_paths, 1, median
  )

  upper_95 <- apply(
    simulated_paths, 1, quantile, probs = 0.975
  )

  # Compare actual prices with simulated distribution
  coverage_95 <- mean(
    prices >= lower_95 & prices <= upper_95
  ) * 100

  median_path_mape <- mean(
    abs(prices - median_path) / prices
  ) * 100

  log_price_rmse <- sqrt(
    mean((log(prices) - log(median_path))^2)
  )

  # Save stock-level results
  gbm_fit_results[[length(gbm_fit_results) + 1]] <-
    data.frame(
      Ticker = ticker,
      Industry = industry,
      Number_of_Prices = length(prices),
      Median_Path_MAPE = median_path_mape,
      Log_Price_RMSE = log_price_rmse,
      Coverage_95_Percent = coverage_95
    )
}

if (length(gbm_fit_results) == 0) {
  stop("No stocks were successfully simulated.")
}

Median Path MAPE: This measures the median percentage error between the simulated GBM price paths and the actual historical stock prices. Lower values indicate that the simulated paths tend to remain closer to the observed prices, suggesting a better fit to the historical data.

Log Price RMSE: This measures the root mean squared error between simulated and actual log stock prices. Lower values indicate smaller discrepancies between the simulated and observed prices, while higher values suggest that GBM struggles to represent the stock’s historical price movements accurately.

95% Coverage: This measures the percentage of actual stock prices that fall within the 95% simulation interval. Coverage close to 95% is consistent with the nominal interval coverage, whereas lower coverage may indicate that the model underestimates uncertainty. Higher coverage is not necessarily better, as wider intervals can capture more observations without providing more precise predictions.

Conclusion across Industries

Overall, The results indicate that GBM can provide a reasonable approximation of historical price movements, but its effectiveness varies considerably between industries. Healthcare and Energy and Utilities produced the lowest median path MAPE values of 9.01% and 9.32%, respectively, whereas Travel, Leisure and Hospitality recorded the highest error at 25.62%. This suggests that GBM is more effective at reproducing price movements for some sectors than others.

The analysis of return distributions further highlights limitations in the model’s assumptions. Consumer Discretionary and Retail had the lowest mean absolute skewness (0.233), but relatively high mean excess kurtosis (6.703), indicating that symmetric returns do not necessarily follow a normal distribution. Healthcare exhibited the lowest mean excess kurtosis (4.960), yet the highest mean absolute skewness (0.374), demonstrating that departures from normality vary across industries. The generally positive excess kurtosis values suggest heavier tails than those expected under a normal distribution, raising concerns about GBM’s ability to represent extreme price movements accurately.

Although mean 95% coverage was high across all industries, ranging from 92.43% to 99.47%, this does not necessarily indicate strong predictive accuracy, as wider confidence intervals can contain observed prices despite substantial differences between simulated and actual paths. Taken together, the findings suggest that GBM is a useful starting point for modelling underlying asset prices, but its assumptions should not be accepted universally. In the context of option pricing and real-options valuation, these limitations are important because an unsuitable price model may affect valuation reliability, particularly where extreme movements or complex price dynamics are significant. However, since this project focuses on historical price simulations rather than directly comparing option prices, further research would be needed to quantify the impact on valuations and assess whether alternative models provide better results.
